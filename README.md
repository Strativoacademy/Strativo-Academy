# 📖 Project Overview

**Strativo Academy** is a modern web-based Forex Trading Education Platform designed to help students learn Forex Trading through structured modules, interactive lessons, quizzes, progress tracking, and practical trading tools.

The platform is being built with a strong focus on simplicity, professionalism, and long-term scalability. Rather than overwhelming learners with information, Strativo Academy follows a step-by-step learning path that helps students build a solid foundation before moving on to more advanced concepts.

The goal is to create a complete learning platform where students can study, practice, track their progress, and continuously improve their trading knowledge in one place.

---

# 🎯 Project Philosophy

Strativo Academy is built around one simple principle:

> **Learn First. Trade Later.**

The platform encourages students to focus on education, discipline, and understanding before risking real money in the financial markets.

Every lesson, quiz, and future feature is designed to help learners develop long-term skills instead of chasing shortcuts or unrealistic expectations.

# 🚀 Installation

## Requirements

Before running Strativo Academy, make sure you have:

- Visual Studio Code
- A modern web browser
- Live Server Extension (Recommended)

---

## Running the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension (recommended).
4. Open `index.html`.
5. Click **Go Live** or open the file directly in your browser.

> **Note:** The current version runs entirely on the client side and does not require a backend server or database.
